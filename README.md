# Kasir Multi

Starter aplikasi POS (Grosir + Restoran) berbasis **Next.js + PWA** sesuai `PROJECT_SPECIFICATION.md`.

## Fitur Awal yang Sudah Dibuat

- Dashboard ringkas
- Halaman kasir grosir (cart, hold transaksi, opsi pembayaran tunai/QRIS/tunda bayar)
- Halaman kasir restoran (table management starter)
- Halaman held transactions (membaca data hold dari localStorage)
- Halaman produk, customer, laporan, settings (starter)
- Manifest PWA (`/public/manifest.webmanifest`)

## Menjalankan Lokal

```bash
npm install
npm run dev
```

## Validasi

```bash
npm run lint
npm run build
```
